- `JOBMATIX_PG_PASSWORD`

**Files Modified:**
- `Services/DatabaseService.cs` - Lines 11-20

### 2. Reports InvalidCastException ✅
**Issue:** Reports threw `System.InvalidCastException: Could not convert System.DateTime to System.Nullable<DateTime>`

**Root Cause:** PostgreSQL query results can contain NULL values, but the code was using direct `Convert.ToDateTime()` without checking for `DBNull.Value`

**Fix:** Added proper null checking before type conversion in three report methods:
1. **Daily Sales Report** - Check date, numInvoices, sales, avgSale for DBNull
2. **Top Customers Report** - Check name, barcode, purchases, spent for DBNull
3. **Top Products Report** - Check code, description, quantity, sales for DBNull

Pattern used:
```csharp
var value = reader["column"] != DBNull.Value 
    ? Convert.ToType(reader["column"]) 
    : defaultValue;
```

**Files Modified:**
- `ViewModels/ReportsViewModel.cs` - Lines 108-113, 318-323, 388-393
